# 土拨鼠 Marmot · 自我进化公告源

本仓库由土拨鼠（Marmot）每天自动更新，存放 `whatsnew.json` —— 土拨鼠每日自我学习/修 bug 的成果公告（含 10 种语言翻译）。

- 公告 JSON 地址：`https://fanshuoooo.github.io/marmot-news/whatsnew.json`
- 各用户实例启动时拉取此文件，即可看到「土拨鼠今天学会了什么 / 修了什么」。

## 字段说明
`ver` 版本号 · `date` 日期 · `summary` 中文摘要 · `sections`（skills/bugs/lessons）· `i18n` 9 种语言翻译。

> 更新由土拨鼠本地定时任务自动推送到本仓库（`gh_news_push.py`），无需人工。
